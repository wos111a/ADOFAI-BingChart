# 🧊 冰谱 Mod（Bing Chart）v1.0.0

**A Dance of Fire and Ice（冰与火之舞）· 把谱面每一个音换成冰音**
作者：**By wos111(机人)**

打开一张谱子，把原曲**每一个砖块**都换成一声「冰」，并且**结合原曲的音高**决定每一声冰是高是低。
转换产物放在 `%temp%`，**原曲文件一个字都不动**。

---

## 它做什么

进关卡后按 **Ctrl + Tab**（可改），开始转换：

1. 读 `.adofai` 谱面，算出**每一颗砖的精确时刻**
2. 读关卡 `.ogg`，检测音频起始点用来**标定时间轴**、并在每颗砖那个瞬间**测原曲的音高**
3. 按「相对开头基准音」的规则给每一声冰定音高
4. 生成两份产物放进 `%temp%\BingChart\<关卡名>\`：
   - `ice.wav` —— 原曲 + 冰音（叠加）
   - `ice_only.wav` —— 只有冰音（用来单独对拍、排查问题）
   - `report.txt` —— 可读的转换报告
   - `ice.ogg` —— 编码后的成品

## 播放方式（这一版的核心改动）

**不再替换游戏自己的音频文件。** 改成：

- 游戏音乐原样播放（叠加模式）或静音（替换模式）
- 我们自己**另开一路音源**放纯冰音层
- **每一帧**都去读游戏自己的播放进度，把冰音掰到同一个位置

为什么要这样：上一版是把游戏正在播的音频「掉包」成冰谱，掉包那一刻起播时间不稳定，
听感就是「忽前忽后」。现在冰音跟着游戏的时钟走，游戏判定砖块用的是同一个时钟，天然对齐。

另外还会：**暂停时冰音跟着暂停**、**从检查点重开时自动重新对表**。

## 两种混合方式

| 模式 | 效果 | 听感 |
|---|---|---|
| **叠加（默认）** | 原曲照常 + 冰音叠上去 | 原曲不变，冰音像装饰层 |
| 替换 | 原曲静音，只放冰音 | 整首歌变成冰块敲击 |

> ★ 想判断「冰有没有踩准」，先把叠加关掉、只听冰音 —— 没被原曲盖住才能一个点一个点数。

## 音高规则

- **基准音**：拿原曲**开头那一小段**的音高当基准
- **每个砖**：在小球落到砖块的那个瞬间，测原曲那一小段的音高；比基准高就升调、低就降调
- 为了避免「跳得太厉害」，做了**压缩**（1 个八度只差 3 个半音）+ **最多 ±7 半音** + **中位滤波**

| 情况 | 额外加成 |
|---|---|
| 单押 | 基准音，不加 |
| 双押 | +2 半音 |
| 三押 | +3 半音 |
| 四押及以上 | +4 半音 |

上面每一项都能在设置页里用滑块调。

## 多押是怎么判的

**官方定义**（查过官方 wiki / Steam 指南 / 萌娘百科 / bilibili wiki）：

- 官方 wiki：「**Multipress = 同时按两个键**」
- Steam 指南：「多次按键!! 在**同时击打两格相邻轨道**的时候出现」
- 萌娘百科 / bilibili wiki：「**双押砖块**：该砖块内还有一个小砖块，需要同时进行 2 次点击；
  **不能在关卡编辑器里复现**；是官方 RJ-X 关卡独有的」
- ⇒ **自制谱里根本没有「双押砖块」这种砖。**

所以自制谱里的「多押」只有一种来源：**相邻两块砖挨得极近**，近到必须几乎同时点两下。

本 Mod 直接用**时间间隔**判定（比用角度准：角度还得乘上 BPM 才是时间）：

> 相邻两砖的间隔 **小于 `多押间隔阈值`（默认 40ms）** 就算「几乎同时按两下」，
> 连着近的一串砖聚成一簇，簇有几个砖就是几押。

实测 186 个真实自制谱、35050 个砖间隔：

| 两砖间隔 | 占比 |
|---|---|
| < 20 ms | 0.73% |
| < 30 ms | 1.76% |
| < 40 ms | 2.78% |
| < 60 ms | 5.25% |

> ⚠️ 一个容易搞错的地方：谱面 `angleData` 里的 `0` **不是**「两砖同一时刻」。
> 它是相对角度，游戏用的是累加出来的角度（归一化到 (0,360]，0 会变成 360），
> 所以**永远不可能有两块砖严格同时**。

## 安装

1. 装 [Unity Mod Manager](https://www.nexusmods.com/site/mods/21)
2. 把 `冰谱Mod` 整个文件夹丢进 `游戏目录\Mods\`
3. 进游戏 → Mods 菜单能看到「冰谱」

依赖游戏目录下的 `ffmpeg\ffmpeg.exe`（游戏自带）。

## 使用

- 进关卡后按 **Ctrl + Tab** 开始转换（长曲子几十秒，期间照常玩原曲）
- 转完原曲自动静音、改放冰谱
- 第一次进关卡会显示一次**操作提示**（想永久关掉就在提示里勾「不再提醒」；
  只是点「知道了」的话，下次开游戏还会弹）
- 想重看提示：设置 → 基础设置 → 「重新打开首次提示」

> ★ **在关卡编辑器里测试的话，退出谱子时记得选「放弃保存」** —— 否则可能把改动存进谱面。
> 弹窗显示时 Mod 会自动屏蔽编辑器的快捷键，避免误操作改到轨道。

## 设置页

UMM 面板里点「设置」进入，分三页：

- **基础设置** —— 开关、音量、音色、快捷键、叠加/替换、首次提示
- **专业设置** —— 音高、多押、冰音听感、时间轴与播放微调、转换参数
- **其他设置** —— 界面偏好、维护、诊断、全部恢复默认

每一组右上角有「重置」只恢复这一组；「其他设置」里有总的「全部恢复默认」。
右上角是红色的 ✕ 关闭。

### 遇到「没声音」怎么办

设置 → 基础设置 → 音色，有个 **「试播冰音层」** 按钮：

- 「试听」= 放**冰音样本本身**（一小段）
- 「试播冰音层」= 放**这个谱子转出来的纯冰音**，**完全不接游戏时钟、不管原曲**

如果「试播冰音层」有声音、进关卡却没声音 → 问题在同步那一段，不在音频。

### 时间对不上怎么办

- 设置 → 专业设置 → **「播放微调」**：**不用重新转换、改完立刻生效**
- 左上角状态卡片会实时显示「偏差 XXXms」，照着往反方向调即可

## 快捷键

默认 `左 Ctrl + Tab`，设置页里可以改成任意组合。作用：开始转换。

## 自定义音色

把 **16-bit PCM 的 `.wav`** 丢进 `audio\` 目录，设置页里点「切换音色」。
mp3 先转：

```bash
游戏目录\ffmpeg\ffmpeg.exe -i 输入.mp3 -ac 1 -ar 44100 -sample_fmt s16 输出.wav
```

> 仓库里另有一份备选音色，**不会随 Mod 一起安装**，也不会成为默认。

## 砖块时间是怎么算出来的

这是整个 Mod 最关键的部分。算法来自两个互相印证的开源实现
（Morilli 的 `adofai2osu!mania.py` 与洛谷 Eznibuil《关于 ADOFAI 自制关卡的一些事》）：

```
neededAngle = 顺时针 ? (startAngle - angle) : (angle - startAngle)   // 归一化到 (0, 360]
msNeeded    = neededAngle / 180 × 60000 / bpm
startAngle  初值 180，处理完第 i 块后 = (下一块是 999) ? angle[i] : (180 + angle[i]) % 360
SetSpeed    Bpm 型赋值；Multiplier 型 **乘当前 bpm**（实测，官方文档措辞会骗人）
!  (999)    三角块（中旋），**也是要按的**，但不更新 startAngle
```

关键点：

- 砖块角度来自谱面的 `angleData`（直接是角度数组）或 `pathData`（每字符一颗砖的紧凑写法）
- 时间轴的准确性用**参考视频（砖块落点）**做过验证，命中率 90% 以上
  > 注意：判断对准不准要用「**砖块时刻**」当基准。
  > 拿「音乐的起始点」当基准会得出「漂移」，但那只是**基准本身不对**（音乐重音 ≠ 砖块时刻）。
- 再用音频起始点做一次**全曲中位标定**
- **必须同时有谱面和音频**才允许转换，任一缺失且未开启兜底时会明确拒绝、不产出文件

## 排查

- Mod 日志写在 **`%USERPROFILE%\AppData\LocalLow\7th Beat Games\A Dance of Fire and Ice\Player.log`**，
  搜 `[BingChart]`。转换开始/完成、播放头读数、每秒同步情况都在里面
- 设置 → 其他设置 → 「诊断」区能看到当前关卡、播放头来源、偏差、重定位次数
- 每次转换会在 `%temp%\BingChart\<关卡名>\report.txt` 落一份可读报告
